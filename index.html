About Me关于我

The developer behind Cycle's Studios

I go by Cycle01, the solo developer and the whole team behind Cycle's Studios. I design, code, light and sound my games myself, mostly in Unreal Engine 5 and Godot.

I started with small projects, and every release since has been a step up: better visuals, tighter mechanics, stronger atmosphere. I'm drawn to tension and mystery. Suburbs that feel wrong, dungeons you need to escape, forests you shouldn't walk into alone.

Lately I've been widening the net. I built my first mobile game, Fling It, and I've been vibe coding browser tools, with three Chrome extensions live on the Chrome Web Store. Different formats, same rule: it has to feel good to use.

Vibe Coding氛围编程

From an idea to the Chrome Web Store

Outside the game engine, I build with vibe coding. I describe what I want in plain language, pair with AI to write and refactor the code, and spend my own time on what actually matters: the idea, how it feels, testing it in a real browser, and polishing it until it's worth publishing.

It turns "I wish this existed" into a shipped tool in a fraction of the time. Three of them are live right now.

01

Spot the itch

Start from a problem I actually have: ads everywhere, forty open tabs, no time to research a genre.

02

Describe the vibe

Plain-language prompts: what it should do, how it should look, how it should feel to click.

03

Test it for real

Load it unpacked, break it on real sites, feed every bug straight back into the loop.

04

Polish & ship

Icons, UI passes, a proper store listing, then publish it to the Chrome Web Store.
